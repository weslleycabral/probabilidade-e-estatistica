Apêndice CDistribuições Comuns

Registramos aqui as distribuições mais usadas em probabilidade e estatística, bem como algumas de suas características básicas.

C.1 Distribuições Discretas

1. Bernoulli\((\theta)\), \(\theta \in [0, 1]\) (igual à Binomial\((1, \theta)\)).
função de probabilidade1: \(p(x) = \theta^x (1 - \theta)^{1-x}\) para \(x = 0, 1\).
média: \(\theta\).
variância2: \(\theta(1 - \theta)\).
função geradora de momentos3: \(m(t) = (1 - \theta + \theta e^t)\) para \(t \in R^1\).

2. Binomial\((n, \theta)\), \(n > 0\) inteiro, \(\theta \in [0, 1]\).
função de probabilidade: \(p(x) = \binom{n}{x} \theta^x (1 - \theta)^{n-x}\) para \(x = 0, 1, \ldots, n\).
média: \(n\theta\).
variância: \(n\theta(1 - \theta)\).
função geradora de momentos: \(m(t) = (1 - \theta + \theta e^t)^n\) para \(t \in R^1\).

3. Geométrica\((\theta)\), \(\theta \in (0, 1]\) (igual à Binomial Negativa\((1, \theta)\)).
função de probabilidade: \(p(x) = (1 - \theta)^x \theta\) para \(x = 0, 1, 2, \ldots\).
média: \((1 - \theta)/\theta\).
variância: \((1 - \theta)/\theta^2\).
função geradora de momentos: \(m(t) = \theta\bigl(1 - (1 - \theta) e^t\bigr)^{-1}\) para \(t < -\ln(1 - \theta)\).

4. Hipergeométrica\((N, M, n)\), \(M \le N\), \(n \le N\), todos inteiros positivos.
função de probabilidade: \[ p(x) = \binom{M}{x} \binom{N - M}{n - x} \Big/ \binom{N}{n} \quad \text{para } \max(0, n + M - N) \le x \le \min(n, M). \] média: \(n \frac{M}{N}\).
variância: \(n \frac{M}{N} \left(1 - \frac{M}{N}\right) \frac{N - n}{N - 1}\).

5. Multinomial\((n, \theta_1, \ldots, \theta_k)\), \(n > 0\) inteiro, cada \(\theta_i \in [0, 1]\), \(\theta_1 + \cdots + \theta_k = 1\).
função de probabilidade: \begin{align*} p(x_1, \ldots, x_k) &= \binom{n}{x_1 \ldots x_k} \theta_1^{x_1} \cdots \theta_k^{x_k} \quad \text{em que cada } x_i \in \{0, 1, \ldots, n\} \\ &\phantom{{}={}} \text{e } x_1 + \cdots + x_k = n. \end{align*} média: \(E(X_i) = n\theta_i\).
variância: \(\Var(X_i) = n\theta_i(1 - \theta_i)\).
covariância4: \(\Cov(X_i, X_j) = -n\theta_i\theta_j\) quando \(i \ne j\).

6. Binomial Negativa\((r, \theta)\), \(r > 0\) inteiro, \(\theta \in (0, 1]\).
função de probabilidade: \(p(x) = \binom{r - 1 + x}{x} \theta^r (1 - \theta)^x\) para \(x = 0, 1, 2, 3, \ldots\).
média: \(r(1 - \theta)/\theta\).
variância: \(r(1 - \theta)/\theta^2\).
função geradora de momentos: \(m(t) = \theta^r \bigl(1 - (1 - \theta) e^t\bigr)^{-r}\) para \(t < -\ln(1 - \theta)\).

7. Poisson\((\lambda)\), \(\lambda > 0\).
função de probabilidade: \(p(x) = \frac{\lambda^x}{x!} e^{-\lambda}\) para \(x = 0, 1, 2, 3, \ldots\).
média: \(\lambda\).
variância: \(\lambda\).
função geradora de momentos: \(m(t) = \exp\{\lambda(e^t - 1)\}\) para \(t \in R^1\).

C.2 Distribuições Absolutamente Contínuas

1. Beta\((a, b)\), \(a > 0\), \(b > 0\) (igual à Dirichlet\((a, b)\)).
função densidade5: \(f(x) = \frac{\Gamma(a + b)}{\Gamma(a)\Gamma(b)} x^{a-1} (1 - x)^{b-1}\) para \(x \in (0, 1)\).
média: \(a/(a + b)\).
variância: \(ab/(a + b + 1)(a + b)^2\).

2. Normal Bivariada\((\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)\) para \(\mu_1, \mu_2 \in R^1\), \(\sigma_1^2, \sigma_2^2 > 0\), \(\rho \in [-1, 1]\).
função densidade: \begin{align*} &f_{X_1, X_2}(x_1, x_2) \\ &= \frac{1}{2\pi \sigma_1 \sigma_2 \sqrt{1 - \rho^2}} \exp\left\{ -\frac{1}{2(1 - \rho^2)} \left[ \begin{array}{c} \left(\frac{x_1 - \mu_1}{\sigma_1}\right)^2 + \left(\frac{x_2 - \mu_2}{\sigma_2}\right)^2 - {} \\[4pt] 2\rho \left(\frac{x_1 - \mu_1}{\sigma_1}\right) \left(\frac{x_2 - \mu_2}{\sigma_2}\right) \end{array} \right] \right\} \\ &\qquad \text{para } x_1 \in R^1, x_2 \in R^1. \end{align*} média: \(E(X_i) = \mu_i\).
variância: \(\Var(X_i) = \sigma_i^2\).
covariância: \(\Cov(X_1, X_2) = \rho \sigma_1 \sigma_2\).

3. Qui-quadrado\((\alpha)\) ou \(\chi^2(\alpha)\), \(\alpha > 0\) (igual à Gama\((\alpha/2, 1/2)\)).
função densidade: \(f(x) = 2^{-\alpha/2} \bigl(\Gamma(\alpha/2)\bigr)^{-1} x^{(\alpha/2)-1} e^{-x/2}\) para \(x > 0\).
média: \(\alpha\).
variância: \(2\alpha\).
função geradora de momentos: \(m(t) = (1 - 2t)^{-\alpha/2}\) para \(t < 1/2\).

4. Dirichlet\((\alpha_1, \ldots, \alpha_{k+1})\), \(\alpha_i > 0\) para cada \(i\).
função densidade: \begin{align*} &f_{X_1, \ldots, X_k}(x_1, \ldots, x_k) \\ &= \frac{\Gamma(\alpha_1 + \cdots + \alpha_{k+1})}{\Gamma(\alpha_1) \cdots \Gamma(\alpha_{k+1})} x_1^{\alpha_1 - 1} \cdots x_k^{\alpha_k - 1} (1 - x_1 - \cdots - x_k)^{\alpha_{k+1} - 1} \\ &\qquad \text{para } x_i \ge 0,\ i = 1, \ldots, k \text{ e } 0 \le x_1 + \cdots + x_k \le 1. \end{align*} média: \[ E(X_i) = \frac{\alpha_i}{\alpha_1 + \cdots + \alpha_{k+1}}. \] variância: \[ \Var(X_i) = \frac{\alpha_i(\alpha_1 + \cdots + \alpha_{k+1} - \alpha_i)} {(\alpha_1 + \cdots + \alpha_{k+1})^2 (1 + \alpha_1 + \cdots + \alpha_{k+1})}. \] covariância quando \(i \ne j\): \[ \Cov(X_i, X_j) = \frac{-\alpha_i \alpha_j} {(\alpha_1 + \cdots + \alpha_{k+1})^2 (1 + \alpha_1 + \cdots + \alpha_{k+1})}. \]

5. Exponencial\((\lambda)\), \(\lambda > 0\) (igual à Gama\((1, \lambda)\)).
função densidade: \(f(x) = \lambda e^{-\lambda x}\) para \(x > 0\).
média: \(\lambda^{-1}\).
variância: \(\lambda^{-2}\).
função geradora de momentos: \(m(t) = \lambda(\lambda - t)^{-1}\) para \(t < \lambda\).

Observe que alguns livros e pacotes de software substituem \(\lambda\) por \(1/\lambda\) na definição da distribuição Exponencial\((\lambda)\) — sempre confira isso ao usar outro livro ou ao usar um software para gerar valores dessa distribuição.

6. \(F(\alpha, \beta)\), \(\alpha > 0\), \(\beta > 0\).
função densidade: \begin{align*} f(x) &= \frac{\Gamma\left(\frac{\alpha + \beta}{2}\right)} {\Gamma\left(\frac{\alpha}{2}\right) \Gamma\left(\frac{\beta}{2}\right)} \left(\frac{\alpha}{\beta} x\right)^{\alpha/2 - 1} \left(1 + \frac{\alpha}{\beta} x\right)^{-(\alpha + \beta)/2} \frac{\alpha}{\beta} \\ &\qquad \text{para } x > 0. \end{align*} média: \(\beta/(\beta - 2)\) quando \(\beta > 2\).
variância: \(2\beta^2(\alpha + \beta - 2)/\alpha(\beta - 2)^2(\beta - 4)\) quando \(\beta > 4\).

7. Gama\((\alpha, \lambda)\), \(\alpha > 0\), \(\lambda > 0\).
função densidade: \(f(x) = \frac{\lambda^\alpha x^{\alpha - 1}}{\Gamma(\alpha)} e^{-\lambda x}\) para \(x > 0\).
média: \(\alpha/\lambda\).
variância: \(\alpha/\lambda^2\).
função geradora de momentos: \(m(t) = \lambda^\alpha (\lambda - t)^{-\alpha}\) para \(t < \lambda\).

Observe que alguns livros e pacotes de software substituem \(\lambda\) por \(1/\lambda\) na definição da distribuição Gama\((\alpha, \lambda)\) — sempre confira isso ao usar outro livro ou ao usar um software para gerar valores dessa distribuição.

8. Log-normal ou \(\log N(\mu, \sigma^2)\), \(\mu \in R^1\), \(\sigma^2 > 0\).
função densidade: \(f(x) = (2\pi\sigma^2)^{-1/2} x^{-1} \exp\left(-\frac{1}{2\sigma^2}(\ln x - \mu)^2\right)\) para \(x > 0\).
média: \(\exp(\mu + \sigma^2/2)\).
variância: \(\exp(2\mu + \sigma^2)\bigl(\exp(\sigma^2) - 1\bigr)\).

9. \(N(\mu, \sigma^2)\), \(\mu \in R^1\), \(\sigma^2 > 0\).
função densidade: \(f(x) = (2\pi\sigma^2)^{-1/2} \exp\left(-\frac{1}{2\sigma^2}(x - \mu)^2\right)\) para \(x \in R^1\).
média: \(\mu\).
variância: \(\sigma^2\).
função geradora de momentos: \(m(t) = \exp(\mu t + \sigma^2 t^2/2)\) para \(t \in R^1\).

10. Student\((\alpha)\) ou \(t(\alpha)\), \(\alpha > 0\) (\(\alpha = 1\) dá a distribuição de Cauchy6).
função densidade: \begin{align*} f(x) &= \frac{\Gamma\left(\frac{\alpha + 1}{2}\right)} {\Gamma\left(\frac{1}{2}\right) \Gamma\left(\frac{\alpha}{2}\right)} \left(1 + \frac{x^2}{\alpha}\right)^{-(\alpha + 1)/2} \frac{1}{\sqrt{\alpha}} \\ &\qquad \text{para } x \in R^1. \end{align*} média: \(0\) quando \(\alpha > 1\).
variância: \(\alpha/(\alpha - 2)\) quando \(\alpha > 2\).

11. Uniforme\([L, R]\), \(R > L\).
função densidade: \(f(x) = 1/(R - L)\) para \(L < x < R\).
média: \((L + R)/2\).
variância: \((R - L)^2/12\).
função geradora de momentos: \(m(t) = (e^{Rt} - e^{Lt})/t(R - L)\).
